## About

**Evidence Vault** is a professional, privacy-first evidence management application for Android. All data is stored locally on-device — no cloud, no external servers, no data leaks.

Organize incidents, disputes, inspections, and legal cases with:
- Photographic evidence with SHA-256 integrity verification
- Chronological timeline tracking
- Document attachment management
- Official PDF report generation
- Offline-first architecture

## Installation

1. Download the latest `EvidenceVault-vX.X.apk` from Releases
2. On your Android device: **Settings → Security → Install unknown apps** → Allow
3. Open the downloaded APK and tap **Install**
4. Future updates will notify you automatically from within the app

---

## In-App Updates

Evidence Vault checks for updates automatically on launch. When a new version is available, you will see an update dialog inside the app with the changelog. Tap **Update Now** to download and install — no need to visit this page manually.

---

## Requirements

- Android 7.0 (API 24) or higher
- ~30 MB storage
- Camera permission (optional, for photo capture)
- Location permission (optional, for GPS auto-fill)

---

## Privacy

- Zero internet access required for core functionality
- No analytics, no tracking, no ads
- All evidence stored in encrypted local SQLite database
- SHA-256 cryptographic integrity on all photos
